# Acumatica Linux Kit

Clone this repository. Open your coding agent in the clone and say:

> Set up Acumatica on this Linux machine. Use AGENTS.md and the setup skill. Do the setup and verify it. Ask me only for access, approval, or a step you can't perform.

Linux owns the workspace and browser. Windows runs Acumatica, IIS, and the Windows build tools. Bring your own authorized Windows and Acumatica access. No product binaries, VM images, or credentials are included.

The kit contains the skills and tooling for setup, multiple isolated sites, source navigation, customization packaging, Acuminator, upgrades, and API and n8n work.
